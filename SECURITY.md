# Security policy

This repository is a blueprint: a specification, models, examples and checks. It runs no service.

## Reporting

Please report security issues privately with GitHub's "Report a vulnerability" (private vulnerability
reporting) on this repository. Do not open a public issue. You will get an acknowledgement within 7 days.

Organization-wide contact: https://cloudlabworks.dev/.well-known/security.txt

## Scope

- Design flaws in the spec or the security model (for example an authorization rule that lets a service
  act as a parent, or a route that exposes hidden items).
- The scripts in `scripts/`.
- **Accidental personal data.** If you find anything that looks like real household data in any file or
  in the history, report it privately and it will be removed.

## Supported versions

Only `main`.
